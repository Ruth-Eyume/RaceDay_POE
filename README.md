# RaceDay – Part 1

## Project Overview

RaceDay is a racing event management system designed to provide an organised way of managing racing events, races, and related information. 

Part 1 focuses on setting up the **backend API**, establishing the initial project structure, creating the database design, and preparing the project for development and containerisation.
 

## Technologies Used

The following technologies are used in Part 1:

* **C#**
* **ASP.NET Core Web API**
* **.NET 10**
* **Visual Studio / Visual Studio Code**
* **Git**
* **GitHub**
* **SQL Database**
* **REST API**
  

The exact folders may increase as the project develops.

## API

The API uses HTTP methods such as:

* `GET` – Retrieve information.
* `POST` – Create new information.
* `PUT` – Update existing information.
* `DELETE` – Delete information.

---

## Database

The database stores the information required by the RaceDay system.

The database design was created before implementing the API so that the API and database can work together correctly.

The database is responsible for storing information such as racing events and other entities required by the system.

The API communicates with the database to retrieve, create, update, and delete data.
